# 跨国临床试验随机分组和揭盲控制台

源提示词摘要：研究中心按分层因素生成随机分组；药品管理员只见发药信息，研究角色正常情况下不可见治疗组；重复受试者和编号冲突被阻止；紧急揭盲需填写原因并形成不可删除审计记录，断网提交进入待处理队列。

## 技术栈

Nuxt 3、TypeScript、Element Plus、Pinia、Nuxt 路由、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62028`

## 可用流程

- 入组：机构、分层因素和受试者编号校验后生成分层区组随机号与治疗组，并分配区组与发药编号。
- 防重复：相同身份标识或研究中心编号会拒绝再次入组。
- 角色隔离：研究者、药品管理员和监察员看到不同的分组隐藏规则，药品管理员任何情况下不可见治疗组。
- 受控揭盲：紧急揭盲只披露该受试者本人的治疗组，同区组其他受试者的组别与发药编号继续隐藏，审计与揭盲记录不记录组别明文。
- 揭盲账本：揭盲记录只追加；撤回或核查不成立可恢复盲态，恢复过程同样留痕。
- 并发与幂等：同一受试者同时只允许一方揭盲成功；写盘失败后按申请编号重试，不重复记账。
- 安全审计：所有操作只能追加，不能删除或改写。
- 离线队列：模拟离线提交进入待提交队列，联网后由授权人员确认入库。
